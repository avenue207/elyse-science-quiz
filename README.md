# Elyse 六年级科学备考 🌟

**Grade 6 Science Quiz — 2024/2025 第一次课堂评估**

A web-based interactive quiz for Elyse's Primary 6 Science exam preparation.

## Features
- ✅ All questions from the classroom assessment (A, B, C sections)
- ✅ Instant feedback per question with explanation (解析)
- ✅ Score tracking with progress bar
- ✅ Final results screen showing total marks and percentage
- ✅ Wrong answer review with detailed explanations
- ✅ Retry option
